# 카드룸 TCG 메인 데모

원피스·포켓몬 카드 전문 쇼핑몰 메인 페이지입니다. 실제 결제나 회원 가입 없이 상품 탐색과 로컬 장바구니를 체험합니다.

## 실행

`npm run dev` 실행 후 http://127.0.0.1:4277 에서 확인합니다. 별도 패키지 설치는 필요하지 않습니다. Python 3가 필요합니다.

## 구성

- 게임별 상품 필터와 카드명·시리즈·번호 검색
- 가격순 정렬, 관심상품, 장바구니 추가/삭제/합계
- 브라우저에 관심상품과 장바구니 저장
- PC/모바일 대응 및 키보드 접근
- 시장 조사: RESEARCH.md

가격, 재고, 카드 상태는 예시입니다. 이미지 출처와 라이선스는 RESEARCH.md, assets/FONT-LICENSE.txt에 기록했습니다. 원피스 공식 카드 이미지의 SAMPLE 워터마크는 원본 그대로 유지했습니다.

## GitHub Pages

배포 주소: https://wongil12.github.io/tcg-demo/

GitHub Pages는 기본 브랜치의 루트 폴더를 게시합니다. `.nojekyll`로 정적 파일을 그대로 제공합니다. 검토용 화면 캡처는 저장소와 배포에서 제외합니다.
